From product link to shipping quote

  1. Open the CAFANS detail page and copy the original seller link if available. Check whether LoveGoBuy accepts the link and supports the selected item.
  2. Save the exact size, color and seller price. For shoes, check whether the chart uses foot or insole length. For clothing, compare flat measurements with a garment you own.
  3. If warehouse QC photos are available, check the variant label, measurements and visible defects before approving dispatch.
  4. Compare shipping quotes for your destination using the packed weight and dimensions. Ask which fees the quote includes before paying.

LoveGoBuy spreadsheet FAQ

What is a LoveGoBuy spreadsheet?

It is a shopping reference for organizing product links, listed prices and sizing notes before ordering through LoveGoBuy. This independent guide uses product listings from CAFANS.

Are the catalog images warehouse QC photos?

These are listing images. Warehouse QC photos, when available, show the item received by the agent.

How do I estimate the full cost?

Add the item price, domestic delivery and agent fees, then check international freight and any applicable import charges. Use the checkout exchange rate for your final estimate.
